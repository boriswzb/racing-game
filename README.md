# NIGHTSHIFT · 霓虹极速

一款可以直接在浏览器里玩的霓虹合成波（Synthwave）风格 3D 街机赛车游戏。无需安装、无需联网、无外部素材，所有车辆、赛道场景、粒子和音效都由代码实时生成。

## 开始游戏

直接双击 `index.html`（或双击 `启动游戏.bat`）即可开始。

- 推荐使用 Chrome / Edge 等现代浏览器
- 建议开启声音；音效和背景音乐使用 Web Audio 实时合成
- 支持键盘和触屏，支持横屏 / 竖屏

## 玩法

午夜环线，3 圈定胜负。你将从最后一位发车，追上 5 名 AI 车手并第一个冲线。

| 操作 | 键位 |
| --- | --- |
| 转向 | `A` / `D` 或 `←` / `→` |
| 油门 | `W` / `↑` |
| 刹车 | `S` / `↓` |
| 氮气 | `Space` / `Shift` |
| 暂停 | `P` / `Esc` |
| 静音 | `M` |
| 重新开始 | `R` |

触屏端：左下角转向，右下角油门 / 刹车 / 氮气。

### 小提示

- 高速过弯时会有离心力，提前反打方向，避免冲出赛道。
- 离开柏油路会快速掉速，并伴随剧烈抖动。
- 氮气会缓慢回充，每完成一圈额外补充。留着在直道使用。
- 追尾会损失速度，保持走线比硬挤更快。
- 最快单圈会保存在浏览器本地（localStorage），下次打开仍然可见。

## 特性

- 伪 3D 起伏赛道，连续弯道、坡顶与透视投影
- 3 圈 6 车竞速，AI 车手具备速度差异与轻量追赶逻辑
- 程序化赛车 / 棕榈树 / 灯柱 / 广告牌 / 龙门架
- 霓虹落日、城市天际线、山脉视差、雾气与速度线
- 氮气、漂移烟雾、碰撞火花、屏幕震动、动态 HUD
- Web Audio 合成引擎声、风噪、氮气声和 Synthwave 背景音乐
- 触屏操作、响应式布局、本地最快圈速记录

## 文件

- `index.html` — 页面结构与 HUD
- `styles.css` — 界面与响应式样式
- `game.js` — 渲染、物理、AI、音效与全部游戏逻辑
- `启动游戏.bat` — Windows 一键启动

## 浏览器兼容

推荐 Chrome / Edge 90+、Firefox 90+、Safari 15+。
游戏使用 Canvas 2D、Web Audio、pointer events 和 `dvh`/`backdrop-filter` 等现代 Web API。
